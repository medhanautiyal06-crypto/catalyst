# Catalyst — Automatic Conflict-Free Timetable Generator
> Generates a clash-free college timetable automatically and keeps every user's view in sync when changes happen.
> ## Features
- Automatic timetable generation (hard and soft constraints)
- Clash detection for teachers, rooms and batches
- Change requests with conflict reasons and alternative slots
- Live synchronisation across windows
- Role hierarchy: Super Admin > Sub Admin > Admin > Faculty / Student
- 5-minute class reminders
- Change log and admin dashboard
